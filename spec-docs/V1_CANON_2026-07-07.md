## §1. THE ONE-PARAGRAPH DEFINITION

**v1 = build + BEGIN (and play) a living season.** A single, save-stable, end-to-end living franchise JK can run on the real `/franchise` route: build league → name GM → pick MLB+farm identities → hire scout → run the full draft (MLB auction + farm auction) with the complete scouting-intelligence system → freeze → launch into a Mode-2 living season with the soul layer ON (fame, morale, news, rivalry, checkpoint development, season-end honors actually running, not dark) → play through the franchise-lens hub → season finale crowns award winners. **Playoffs are deferred** (JK 2026-06-30, Decision E) — the next milestone after v1, not part of it. *(V1_PLAN_2026-06-30.md §1, verbatim basis.)*

Restated in build terms: v1's scope is **A-to-Z, LEAGUE SETUP → END OF REGULAR SEASON**; playoffs/offseason are deferred (Decision E); in-season GM advisor tools (dead-cap display, call-ups/trades advisor beyond what's specified below) are a separate thread excluded from this contract. *(V1_BUILD_STATUS.md header, lines 3-4.)*

**The acceptance gate — one gate, no substitutes:** JK's browser sign-off on real data. Nothing else closes v1. The build sequence that must precede it, in strict order: feature freeze → saved-game migration check → flip the 11 soul flags ON → §16 Simulation-Gate tuning (~100 feel-numbers) → flip the live `/franchise` route to canon → **JK plays it in the browser.** Any failure loops back to tuning, never back to building. *(V1_PLAN_2026-06-30.md §3 Phase 4, steps 10-14; V1_BUILD_STATUS.md §4 step 6; PATHWAY_TO_V1_2026-07-07.md Phase 5 and Part 8 row 5 — all three docs state this identically.)*

### The draft economy laws (binding, dated)

- **Hard salary cap.** JK ruling 2026-07-03 (`DECISIONS_LOG.md` "HARD SALARY CAP in league settings") replaces the pool-relative "Option B" cap with an absolute dollar ceiling the GM sets in league settings; pool extraction must be cap-aware; designer + auction display and enforce that one number.
- **IV = salary.** The canonical player valuation (`kblIV`) *is* the draft salary — the single price basis referenced throughout `SCOUTING_INTELLIGENCE_SPEC.md` and `DRAFT_ECONOMY_RESET_2026-07-05.md` §7 (key surfaces map).
- **D17 positional-scarcity ladder.** JK ruling 2026-07-04 (`DECISIONS_LOG.md`): C 1.12 · SS 1.10 · CF 1.06 · 2B 1.03 · 3B 0.97 · RF 0.94 · LF 0.90 · 1B 0.88 — payroll-neutral by construction (unweighted mean = 1.00), scales only `midSal`/`sal100` anchors in the 8 primary-fielder blocks. Secondary-position scarcity credit deferred to v1.1.
- **Arm-role repricing.** JK ruling 2026-07-04 (`DECISIONS_LOG.md`): pitcher arm-role price scalings SP 1.00 · SP/RP 0.80 · CP 0.65 · RP 0.55, one SP-shaped curve family; canonical IV prices expected production only — SP/RP flexibility value is explicitly routed to the roster/pool-construction layer and the v1.1 economy batch, not `computeIV`.
- **Reserve prices (Lever A), with the k-dial and the exhaustion amendment.** `FABLE_RESERVE_PRICE_DESIGN_2026-07-07.md`: reserve = `max(LEAGUE_MINIMUM_SALARY, round(k × IV))`; k ∈ {0 (off), 0.50, 0.65 (default), 0.80}; opening bid = reserve; auto-fill charges the reserve. **Exhaustion amendment (2026-07-07, post-REJECT remediation):** in pool-exhaustion cleanup ONLY, reserve yields to legal completion — charge `max(minSalary, min(reserve, team-affordable))` — never in live bidding, lone-survivor claims, or forced fills before exhaustion. Merged PR #25, 2026-07-07 (`V1_BUILD_STATUS.md` §0 item 1f); JK feel-pass on a real draft is a **pending gate**, not yet closed.
- **Pool presets: balance / quality / source.** Session-scoped Draft Setup controls, confirmed live in `UI_TRUTH_MAP.md` row 28 and Part-A finding 1: Pool Balance (Grounded/Balanced/Juiced), Pool Quality (stops 64/66/68/70-baseline/72/74/76), Pool Source (team-roster-priority / full-player-pool / import-from-branded-teams), Cap Fit diagnostic + Suggested Neutral Cap.
- **Shills-advisory floor ruling.** PR #22, 2026-07-07 (`V1_BUILD_STATUS.md` §0 item 1c): in-session recompute + a shills-advisory floor fix that lets a 30-club room lock with **zero hand-adds** (browser-proven: pool 660 = exact demand). Distinct from the earlier 2026-07-02 shill-count ruling (default = 2 for an 8-team league; `DECISIONS_LOG.md` "post-C3 direction" item 1).
- **Two-mode pool system.** JK ruling 2026-07-02 (`DECISIONS_LOG.md` "two pool-construction modes"): **Mode A (design-first)** — GMs lock archetype + per-position preferences, the engine extracts the pool from a larger uploaded universe (the POOL-FROM-DEMAND ticket); **Mode B (pool-first)** — lock the pool first, then team-setup hubs gray out unsupportable archetypes/player-archetypes. Selectable per league; completion always guaranteed; extraction is machine-side (no GM sees another's asks).
- **Require-a-closer (RATIFIED — see §6, 2026-07-07).** SHIPPED and live on trunk (commit `f71059ec`, 2026-07-04): a legal roster now requires ≥1 true closer (role CP) — `LEGAL_ROSTER.minClosers=1` + `isCloser` (`src/data/rosterConstruction.ts:37,153`), enforced across construction/board/market layers (`rosterDesignFeasibility.ts:322`, best22Target, archetypeBalanceSimulator, auctionBoardFrame, poolFromDemand, draftPoolExtractor) and the in-season legality gate. CP price unchanged.

### The Scout vs Assistant GM canonical split
`SCOUTING_INTELLIGENCE_SPEC.md` §1: **the Scout** evaluates talent — **farm only** — with 3/5/7-band confidence *derived from the farm archetype* (never a GM choice); **the Assistant GM** does roster construction + money — MLB draft and in-season — reasoning *across* archetypes because MLB ratings are public (construction is the skill, not rating-accuracy). Both are GM-named entities living in the per-league identity bundle alongside the Manager and Beat Reporter (§2 of the same spec).

### Soft luxury tax as Asst-GM advisory
Confirmed (allowed, warned, taxed) — JK Decision B, 2026-06-30 (`V1_PLAN_2026-06-30.md` §5). The wrong-fit penalty is **RESOLVED as Option A**: a graduated, visible debit from the draft budget the moment you win an off-fit player (bid + penalty, shown *before* the bid), paid once at the draft; the player then carries only his intrinsic salary into the season (`SCOUTING_INTELLIGENCE_SPEC.md` §3.3). Design committed; **build queued** (S7 outstanding item above).
