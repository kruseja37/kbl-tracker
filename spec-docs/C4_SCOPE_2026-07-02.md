## RISKS
- The per-league identity store touches 4–5 registries (backup/sync/L-SIM/save-slot) — the new-own-DB gotcha; get it wrong = silent identity data loss.
- `buildLotViewFromSession` (the live-session→market-model adapter) is exported but **called from nowhere** — the pure core is tested, the in-app session→view→React path is unproven. Budget a real end-to-end verify.
- `projectBidVsPass` re-prices the whole pool per call — must be memoized per lot or it re-runs on every keystroke.
- Every C4 surface is USER-VISIBLE → JK browser sign-off on real data (the slowest, un-parallelizable gate).

- **C4-A — the spine (highest value, least dependent):** the draft→franchise **handoff** + GM/seat identity **persistence** + the per-league identity store. This is what turns "a finished draft" into "a playable season." Recommend FIRST.
